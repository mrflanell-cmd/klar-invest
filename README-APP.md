# KLAR INVEST

KLAR INVEST is an iPhone-friendly web scanner. Deploy with Render Blueprint (render.yaml). After Render reports Live, open the assigned HTTPS URL in Safari and choose Share → Add to Home Screen.

It is not hosted yet. Its Swedish symbol dataset is community-maintained and may omit First North or contain stale entries. Yahoo Finance chart API is unofficial and rate-limited. The app explicitly reports instrument and data coverage. No orders.
